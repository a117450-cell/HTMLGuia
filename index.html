Elementos HTML em Bloco e em Linha

Cada elemento HTML possui um valor de exibição padrão (display), dependendo do tipo de elemento que é. Os dois valores de exibição mais comuns são bloco (block) e em linha (inline).

☐ Elementos ao Nível de Bloco

Um elemento ao nível de bloco começa sempre numa nova linha e o navegador adiciona automaticamente alguma margem (espaço) antes e depois do elemento.

Um elemento ao nível de bloco ocupa sempre toda a largura disponível (estende-se para a esquerda e para a direita até onde conseguir).

Dois elementos em bloco muito utilizados são: <p> e <div>.

  • O elemento <p> define um parágrafo num documento HTML.
  • O elemento <div> define uma divisão ou uma secção num documento HTML.

➜ Elementos em Linha

Um elemento em linha não começa numa nova linha.

Um elemento em linha ocupa apenas a largura estritamente necessária para o seu conteúdo.

Elemento <div>

O elemento <div> é frequentemente utilizado como um contêiner para outros elementos HTML.

O elemento <div> não tem atributos obrigatórios, mas os atributos style, class e id são muito comuns.

Elemento <span>

O elemento <span> é um contêiner em linha utilizado para marcar uma parte de um texto ou de um documento.
