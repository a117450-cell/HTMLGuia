O que são tags semânticas?

Uma tag semântica transmite significado claro tanto para o desenvolvedor como para o navegador/motores de busca. Em vez de usar div para tudo, as tags semânticas descrevem exatamente a função do conteúdo.

Exemplo de não semântico:

<div id="header"> ou <span class="titulo">

Exemplo de semântico:

<header>, <article>, <nav>, ETC

Principais tags semânticas e Exemplos

1. <header> e <nav>

O <header> representa o cabeçalho de uma página ou secção. O <nav> é usado para blocos de links de navegação principais.

Exemplo de Código:

<header>
  <h1>Meu Blog</h1>
  <nav>
    <a href="#home">Início</a>
    <a href="#sobre">Sobre</a>
  </nav>
</header>

2. <main>, <article> e <section>

  • <main>: Conteúdo principal e exclusivo do documento.
  • <article>: Conteúdo autónomo (ex: post de blog, notícia).
  • <section>: Agrupamento temático de conteúdos.

Exemplo de Código:

<main>
  <article>
    <h2>Notícia do Dia</h2>
    <p>Texto do artigo...</p>
  </article>
</main>

3. <aside> e <footer>

O <aside> guarda conteúdo secundário/lateral (ex: sidebars, publicidade). O <footer> define o rodapé da página ou secção.

Exemplo de Código:

<aside>
  <h3>Links Úteis</h3>
</aside>

<footer>
  <p>&copy; 2026 Todos os direitos reservados.</p>
</footer>
